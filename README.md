# Veggie Dash — 蔬菜跑跑

手機直向 Crash Game 互動 Demo。玩家有 30 秒選擇角色與下注，最多同時進行兩注；開跑後可在追兵抓到角色前手動或自動 Cash Out。

> 本專案只使用虛擬籌碼。96% 是數學模型的長期理論與測試目標，不代表真實金錢遊戲、法規認證或第三方實驗室驗證。

## 遊戲內容

- 6 個能力鮮明的蔬菜角色與 21 種雙角色組合
- 兩個下注面板共用下注金額，可使用不同角色與 Auto Cashout 倍率
- 四幀角色跑步動畫、移動背景、雙路追兵、Cash Out 與被捕特效
- SHA-256 回合承諾；爆點與角色隨機效果都預先由同一組 Seed 決定
- 六種單角與 21 種雙角組合分別校準，含回饋池後以 96% 為長期模擬目標
- 手機安全區、觸控操作、禁止意外頁面縮放與小螢幕排版

## 爆點曲線

每局先產生 Server Seed，並在下注前公開 `SHA-256(seed)`。爆點亂數取自：

```text
U = first52bits(SHA-256(seed + ":crash")) / 2^52
```

鎖定下注後，系統依角色、雙注組合、投注比例及策略倍率算出開局存活率 `q` 與曲線係數 `k`，再把已承諾的 `U` 映射成爆點：

```text
P(Crash ≥ m) = q × (1.01 / m)^k       （1.01 ≤ m < 100）
```

`q` 控制 1.00× 的比例，`k` 控制後段下降速度。角色獎勵較強時，系統主要提高後段風險，不再把所有成本集中到 1.00×；目前單角與雙角配置的 1.00× 理論比例約為 8.9%～24.7%。

角色能力層以 92% 為核心目標；回饋池記錄核心淨損失的50%，只有正餘額達到浮動門檻且足以負擔「實際派彩－原本自然派彩」時才會介入。負餘額會保留並由後續損失先補平，因此同一筆損失不會重複進水。長期理論值為 `92% + (1 - 92%) × 50% = 96%`。手動 Cash Out 若偏離角色能力的策略區間，實際短期回報與波動仍會改變。

追擊條與獵人距離是純動畫演出，不讀取爆點，不能用來預測本局結果。
